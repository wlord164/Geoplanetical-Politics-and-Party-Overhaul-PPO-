# Politics and Party Overhaul (PPO)

A Geoplanetical mod that expands party politics, elections, uprisings, and historical conflicts.

## Install or update

Requires **Geoplanetical 1.1.6 on Windows Steam (build 26784265)**, [Node.js LTS](https://nodejs.org/en/download), and about 4 GB free on the Steam library drive.

1. Close Geoplanetical and extract the PPO ZIP into a new folder.
2. Run `Install Party Mod.cmd` from the newly extracted folder, even if PPO is already installed.
3. Launch Geoplanetical through Steam.

To remove PPO, close the game and run `Restore Original Game.cmd` from that folder. Keep PPO campaign saves for use with a compatible PPO installation.

## Where to start

- **New Game → Create Party** to choose an ideology and start your own party.
- **Politics → Assembly** for the seat chart. Hover over a seat for the party name or select it to open the party’s leaders and ideology.
- **My Party** for Congress, campaigns, staff plans, foreign funding, and uprisings.
- **Defense → Historical Conflicts** to browse wars, check who controls territory, and review peace options.
- **Defense → Frontline** or **At War** to organize armies and issue orders on the war map.

You can continue an existing campaign. Start a new game to load the January 1, 2026 opening register. PPO includes its opening names and portrait assets. The two Workshop party identity mods can be disabled.

### Frontline orders

Select an army above the command console or press **+** to group divisions from the map or roster. Click the highlighted contact line to assign the whole front, or drag along it to assign a sector.

Choose **Save & Hold** to defend the assigned line. To attack, select **Set objective**, pick a province, review the arrow, and choose **Save & Advance**. For an army already at the front, **Hold** stops its push while it continues defending. **Advance** resumes its saved objective when the route is valid. The army's order shows its activity and any reason it is waiting.

The dot at the arrowhead marks the selected destination. The dashed line follows the far edge of the target province and adjusts its length and spacing as you zoom.

Armies can run orders in parallel. Queue a follow-on order to start after the current objective is secured. When an advance finishes, its arrow disappears and the army takes up the connected front nearest the objective. A queued order starts from that front. Saved campaigns retain the armies, colors, postures, and queued orders.
