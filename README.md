# Politics and Party Overhaul (PPO)

A Geoplanetical mod that expands party politics, elections, uprisings, and historical conflicts.

## Install or update

Requires **Geoplanetical 1.1.5 on Windows Steam (build 26734764)**, [Node.js LTS](https://nodejs.org/en/download), and about 4 GB free on the Steam library drive.

1. Close Geoplanetical and extract this compatibility ZIP into a new folder.
2. Run `Install Party Mod.cmd` from the newly extracted folder, even if PPO is already installed.
3. Launch Geoplanetical through Steam.

To remove PPO, close the game and run `Restore Original Game.cmd` from that folder. Keep PPO campaign saves for use with a compatible PPO installation.

## Where to start

- **New Game → Create Party** to choose an ideology and start your own party.
- **My Party** for Congress, campaigns, staff plans, foreign funding, and uprisings.
- **Defense → Historical Conflicts** to browse wars, check who controls territory, and review peace options.
- **Defense → Frontline** to select divisions, organize armies, and give them colored fronts and Hold or Advance orders.

You can continue an existing campaign. Start a new game to see the full historical opening setup.

### Frontline prototype

Open **Frontline** under **Defense** and choose an active land war. Use an empty slot or the **+** button to create an army. Name it, choose a general, and drag a box around its divisions on the globe, or select them from the roster. You can save the army before drawing its sector. Mark the ends of the sector and the colored line follows the live contact border between them.

Set **Hold** to defend and replenish, or draw an objective arrow and set **Advance**. Arrows start at the center of the front and extend straight toward the objective where land permits. They bend around water, snap offshore objectives to reachable land, and show the army name along the shaft.

Armies can run orders in parallel. Queue a follow-on order to start after the current objective is secured. When an advance finishes, its arrow disappears and the army takes up the connected front nearest the objective. A queued order starts from that front. Saved campaigns retain the armies, colors, postures, and queued orders.
